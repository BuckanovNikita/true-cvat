# Каталог `local/`

Здесь собрано всё, что относится к машине, на которой форк разрабатывается, и
к прошлым работам, а не к тому, что форк распространяет. Секретов здесь нет,
поэтому каталог лежит в ветке `develop` и в её истории. Ветка `release` — это
`develop` без этого каталога, и ничем другим она не отличается
([ADR 0009](../DOCS.md#adr-0009)).

| Путь | Что это |
| --- | --- |
| `team-analytics-stack/` | Тестовый стенд в Kubernetes, на котором идут проверки вживую ([README](team-analytics-stack/README.md)). Его значения по умолчанию называют кластер этой машины. |

## Старые пути

Свидетельства (`evidence/`), локальный трекер (`scratch/`) и `INFRA_MIGRATION.md`
удалены; их тексты остаются в истории git (`DOCS.md`, раздел «History»). Ревизии,
которые называют записи до 2026-11-19, — это ревизии репозитория
`BuckanovNikita/cvat-fork`; соответствие новым ревизиям — в трейлерах
`Landed-as:` коммитов `develop`.
