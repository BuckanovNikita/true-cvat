# Каталог `local/`

Здесь собрано всё, что относится к машине, на которой форк разрабатывается, и
к прошлым работам, а не к тому, что форк распространяет. Секретов здесь нет,
поэтому каталог лежит в ветке `develop` и в её истории. Ветка `release` — это
`develop` без этого каталога, и ничем другим она не отличается
([ADR 0009](../docs/adr/0009-three-branches-in-a-github-fork-and-develop-rebased-onto-upstream.md)).

| Путь | Что это |
| --- | --- |
| `evidence/` | Датированные свидетельства проверок: что запускалось, на какой ревизии и с каким итогом. Новые свидетельства пишутся сюда. |
| `scratch/` | Локальный трекер до 2026-11-17: спецификации, планы и тикеты. Его заменил Linear; файлы остаются как запись ([правила](../docs/agents/issue-tracker.md#local-tracker-archive)). |
| `team-analytics-stack/` | Тестовый стенд в Kubernetes, на котором идут проверки вживую ([README](team-analytics-stack/README.md)). Его значения по умолчанию называют кластер этой машины. |
| `test-stack-on-a-shared-machine.md` | Как стенд делит общий кластер, что проверяет его render-проверка и что о нём видно в публичном репозитории. |
| `INFRA_MIGRATION.md` | Перенос инфраструктуры проверки на Kubernetes и его итог. |

## Старые пути

Файлы перенесены сюда 2026-11-19 без изменения текста. Перенесённые записи не
переписывались, поэтому в них самих, в старых свидетельствах и в двух
комментариях кода (`cvat/apps/team_analytics/core/config.py`,
`cvat/apps/team_analytics/sql/control/cutover_find.sql`) встречаются прежние
пути. Читать их нужно так:

| Прежний путь | Теперь |
| --- | --- |
| `docs/evidence/<путь>` | `local/evidence/<путь>` |
| `.scratch/<путь>` | `local/scratch/<путь>` |
| `verify/team-analytics-stack/<путь>` | `local/team-analytics-stack/<путь>` |
| `INFRA_MIGRATION.md` | `local/INFRA_MIGRATION.md` |

Относительные ссылки внутри перенесённых записей по той же причине могут вести
на прежнее место. Ревизии, которые называют записи до 2026-11-19, — это ревизии
репозитория `BuckanovNikita/cvat-fork`; соответствие новым ревизиям — в
[свидетельстве о переносе](evidence/2026-11-19-true-cvat-migration.md) и в
трейлерах `Landed-as:` коммитов `develop`.
